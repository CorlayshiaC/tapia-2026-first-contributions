# Contributing

This repository exists so people can practise the contribution workflow. Contributions that are practice are welcome — that is the point.

## What to contribute

Add a file at `contributors/YOUR-GITHUB-USERNAME.md`. Keep it to a few lines. See `contributors/example-user.md`.

Improvements to the README or these guidelines are also welcome, especially if something confused you the first time through.

## What the checks do

One automated check runs on every pull request. It confirms that:

- files in `contributors/` end in `.md`
- your file is not empty
- you did not modify someone else's file

If it fails, click **Details**, read the last line, and push a fix to the same branch. The pull request updates itself.

## Pull requests

- One thing per pull request
- A title that says what changed
- A sentence of description, and `Closes #N` if it relates to an issue

## Code of conduct

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
